# Grok Build: CRM visual limpio — valor de decisión (V3)

## Goal
Clean the phone CRM: fewer numbers-for-numbers-sake; more visual charts that help a Venezuelan store/restaurant owner decide. Max 3 actions. Movement only. es-VE tú. $0. No Jev. No invented sales.

## UI
- Qué pasó: 2–3 short sentences
- Qué decidir: ≤3 cards (action + when + one evidence line + money-plain why)
- Visuals: occupancy by 20-min bars (simple), optional dwell “how long people stay” histogram or 3 buckets (<1m / 1–2m / ≥2m), one heatmap + short video
- Remove dense tables, engineer jargon, decimal noise
- Compact “Esto no sabemos” (no sales/ticket)

## Primary case
Best current restaurant run (Kitchen DIVE / dwell-enriched). Keep tunnel; restart CRM standalone if needed.

## RESULT
`outbox/RESULT_CRM_VISUAL_DECISIONS_V3.md` + phone URL checklist.

## Done when
Owner decides in <1 min from visuals + 1–3 actions, not a data dump.
